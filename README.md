# Devansh Sahu - Personal Portfolio

Welcome to the source code for my personal portfolio website! This project showcases my skills, experience, and projects through a modern, highly interactive, and beautifully designed web experience.

## ✨ Features

- **Modern Tech Stack**: Built with [Next.js](https://nextjs.org/) (App Router) and [React 19](https://react.dev/).
- **Stunning UI/UX**: Styled with [Tailwind CSS](https://tailwindcss.com/) for a fully responsive, utility-first design approach.
- **Smooth Animations**: Uses [Framer Motion](https://www.framer.com/motion/) for fluid page transitions, scroll reveals, and micro-interactions.
- **Buttery Smooth Scrolling**: Integrates [Lenis](https://lenis.studiofreight.com/) for seamless and highly performant custom scroll behavior.
- **Beautiful Icons**: Powered by [Lucide React](https://lucide.dev/).
- **Type-Safe**: Developed completely in [TypeScript](https://www.typescriptlang.org/).

## 🚀 Getting Started

First, clone the repository and install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the portfolio in action.

## 📁 Project Structure

- `/app`: Contains the Next.js App Router layout and main page.
- `/components`: Contains all reusable UI components (e.g., Portfolio sections, navigation, interactive elements).
- `/public`: Static assets including images, my resume (`Devansh-Sahu-Resume.pdf`), and fonts.
